# Technical knowledge worker / builder (generic, public-safe)

This profile describes a role, not a person. It contains no private information and is written so the scan built from it can be shared publicly.

## Jobs
- deep research and evidence gathering: answer technical and market questions with cited, verifiable sources
- coding and software building: write, refactor, test and ship small-to-medium software projects with coding agents
- technical and engineering knowledge work: read specs, papers and codebases; produce analyses, designs and decisions
- presentations: turn research and analysis into slide decks quickly
- writing and content creation: draft, edit and publish long-form writing that reads as human, not generic AI text
- workflow automation: automate recurring multi-step workflows across apps and APIs
- file and document work: create, convert, extract from and edit PDF, Word, spreadsheet and Markdown documents
- background and persistent execution: run long or scheduled agent tasks unattended and review the results later
- personal productivity: manage tasks, notes, email and calendar with less manual effort and lower token/context cost
- discovering and evaluating new AI capabilities: find, test and benchmark new AI tools before adopting them

## Constraints
- budget: prefer what is already paid for; a new paid tool must replace or clearly beat something owned
- privacy: no tool that trains on private inputs; read-only scopes preferred; no secrets in prompts or profiles
- security: third-party MCP servers, plugins and skills are code with permissions; review before any install
- time: a trial must fit in about one hour on a real job
- scope: this run is discovery and ranking only; nothing is installed
